# CudyRoute — Cudy WR3000U v1

Независимая ARM64-адаптация [RouterBox](https://github.com/nekl3103/RouterBox) с ядром [sing-box-lx](https://github.com/Leadaxe/sing-box-lx), подписками и русским интерфейсом LuCI. Связь с авторами оригинала и их одобрение не подразумеваются. См. [атрибуцию](docs/UPSTREAM.md) и [LICENSE](LICENSE).

| Параметр | Целевая платформа |
|---|---|
| Роутер / board | Cudy WR3000U v1 / `cudy,wr3000u-v1` |
| OpenWrt | 25.12.x, исходные данные устройства: 25.12.6 |
| Target / APK | `mediatek/filogic` / `aarch64_cortex-a53` |
| Go / CPU | `linux/arm64`, ARMv8.0, CGO отключён |
| Приложение | 0.4.0 |
| Ядро | sing-box-lx 1.14.2-lx.12, закреплённый commit |

Репозиторий адаптирован для устройства пользователя. Проверки сборки и конфигурации не заменяют испытание на физическом WR3000U. Перед включением VPN сохраните настройки OpenWrt.

## Установка готового комплекта по SSH

Для установки не нужны Git, Go, Docker или SDK на роутере. Нужен архив `cudyroute-wr3000u-0.4.0.tar.gz`, полученный из сборки или Releases этого проекта.

С компьютера (подставьте адрес своего роутера):

```sh
scp -O cudyroute-wr3000u-0.4.0.tar.gz root@192.168.1.1:/tmp/
ssh root@192.168.1.1
```

На роутере:

```sh
cd /tmp
tar -xzf cudyroute-wr3000u-0.4.0.tar.gz
cd cudyroute-wr3000u
sh ./install.sh --check
```

После успешной проверки установите:

```sh
sh ./install.sh --flash
```

Откройте LuCI → **Сервисы → CudyRoute**. На новой установке VPN выключен. Добавьте подписку, настройте правила и включите VPN через интерфейс.

Если другой VPN уже работает, используйте `sh ./install.sh --disabled`: пакеты установятся без запуска и автозапуска CudyRoute. Остановите другой перехватчик трафика перед включением CudyRoute. Затем запустите контроллер `/etc/init.d/cudyroute start`; автозапуск — `/etc/init.d/cudyroute enable`.

Установщик проверяет модель, target, архитектуру, серию OpenWrt, контрольные суммы, свободные RAM и flash. Подпись APK проверяется; обход проверки архитектуры или подписи не нужен. Зависимости и модули ядра загружаются из репозиториев установленной прошивки. Финальный объём зависимостей дополнительно проверяет APK.

После публикации релиза доступна установка через `bootstrap.sh`. До появления релиза ссылка Releases не содержит установочных файлов.

## Возможности

- Подписки: URI, Base64, sing-box JSON, поддерживаемые Clash YAML и отдельные серверы Xray JSON.
- VLESS/REALITY/XHTTP, Hysteria2, TUIC, Shadowsocks, WireGuard/AmneziaWG и другие возможности закреплённой сборки ядра. Совместимость конкретного профиля проверяется ядром; версии AWG и готовая регистрация WARP здесь отдельно не гарантируются.
- Правила по сервисам, доменам, IP/CIDR и устройствам; порядок сверху вниз, первое совпадение.
- Направления VPN / напрямую / блокировка; отдельный сервер или пул для UDP.
- DNS, проверка серверов, резервирование, журнал, текущие соединения.

Для схемы «всё через VPN, Россия напрямую» задайте исключения RU выше общего VPN-маршрута. Исключение вроде «Яндекс через VPN» должно находиться выше общего правила RU. Точность определяется выбранными доменными/IP-списками.

Голос игры можно направить на отдельно добавленный совместимый WARP/WireGuard-профиль правилами по подтверждённым адресам голосовых серверов. Готового универсального правила ARC Raiders нет; успешный HTTPS-тест не подтверждает прохождение UDP.

## Память и отключение

Сжатые бинарники хранятся во flash, исполняемые файлы распаковываются в `/tmp/cudyroute`. Поэтому требуется и flash, и RAM. Точные размеры находятся в `manifest.json`. Сохранены ограничения оригинала: 64 активных сервера, 32 селектора и не более двух активных WireGuard/AmneziaWG/MASQUE-туннелей суммарно.

Отключайте VPN кнопкой в интерфейсе. Простая остановка службы сохраняет защитные правила. Аварийное восстановление прямого выхода:

```sh
/etc/init.d/cudyroute stop
/usr/bin/cudyroute cleanup
```

Удаление: `apk del luci-app-cudyroute cudyroute-core`. Настройки остаются в `/etc/cudyroute`.

## Сборка и GitHub

На компьютере нужны Go 1.26.8, Git, Python 3, OpenSSL и Docker. На Linux/macOS:

```sh
./scripts/build.sh
```

Результат — в `dist/`. Ядро и контроллер собираются как ARM64; APK маркируются `aarch64_cortex-a53`. Исходники ядра и submodules закреплены в Git. Для упаковки применяется закреплённый Alpine-образ с APK 3.

Репозиторий по умолчанию для обновлений — `henk911/RouterBox_CUDY`. В GitHub Actions используется `${{ github.repository }}`, поэтому сборка в другом репозитории получает его адрес автоматически.

Workflow **Build CudyRoute** проверяет код, собирает APK, запускает тесты конфигурации с ядром и сохраняет Artifacts. Первый успешный push в `main` этого репозитория автоматически публикует `v0.4.0` в Releases. Уже опубликованные файлы повторный запуск не изменяет. Следующие версии можно публиковать тегами `v*` после обновления версии пакетов. Для постоянной подписи создайте секрет `CUDYROUTE_APK_SIGNING_KEY` с PEM-ключом; приватный ключ никогда не входит в комплект.

Подробности публикации и установки: [docs/INSTALL.md](docs/INSTALL.md).
